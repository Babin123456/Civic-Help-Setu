# Redesign Nearby Offices Permission and No-Results Panels

## Purpose
Enhances the user experience on the Nearby Offices directory when handling location permissions and empty search outcomes.

## Key Improvements
- **Graceful Permission Degradation**: Clear explanation of coordinate usage; denial does not block manual district or state filtering.
- **Active Filter Disclosure**: Outlines exact combination of state, district, or office type filters causing the empty result set.
- **Accessible State Handling**: High contrast status cards, ARIA regions, and responsive keyboard action buttons.
