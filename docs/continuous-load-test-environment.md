# Continuous Load-Test Environment with Production-Shaped Synthetic Data

## Purpose
Provides continuous performance validation using privacy-safe synthetic citizen datasets with realistic statistical distributions and hot-key skew modeling across baseline, spike, soak, and stress scenarios.

## Features
- **Privacy-Safe Pseudonymization**: Generates synthetic citizen application records without PII.
- **Configurable Workload Profiles**: Baseline, Spike, Soak, and Stress testing configurations with explicit error budget and P99 latency thresholds.
- **Automated SLO Verification**: Automatically checks observed latency distributions and error rates against contractual thresholds.
