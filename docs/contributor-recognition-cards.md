# Contributor Recognition Cards with Contribution-Type Filters

## Overview
Adds a filterable contributor recognition directory to the Open Source / Community Hub section of Civic Help Setu. It highlights verified open-source contributors categorized by their primary contribution areas (Frontend / UI, Accessibility, Civic Data, AI & Policy, Testing & QA, Documentation).

## Key Features
- **Accessible Filter Toolbar**: ARIA radiogroup controls for instant category selection.
- **Audible Announcements**: Live screen-reader updates reflecting filtered result counts.
- **Safe Profile Anchoring**: Points directly to verified GitHub profiles without tracking or data invention.
- **Empty State Resilience**: Clear call to action when a selected category contains no tagged contributors yet.
