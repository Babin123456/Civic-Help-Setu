# Redesign Eligibility Page Tabs and Applicant Context Panel

## Purpose
Revamps the tab navigation and applicant context headers for the Universal Eligibility journey. Enables clean separation between the guided wizard, scheme comparative matrix, and saved assessments while keeping multi-applicant context transparent without cluttering mobile screens.

## Features
- **Applicant Context Pill**: Displays evaluated individual, relationship tier, age, and economic category.
- **Scrollable & Wrap-Safe Tablist**: Full keyboard traversal and WCAG-compliant ARIA tablist/tabpanel mapping.
- **Unsaved Changes Gate**: Guard modal preventing accidental context or tab switches when incomplete evaluation data is present.
