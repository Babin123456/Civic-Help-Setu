# Improve Eligibility Wizard Question and Progress Presentation

## Purpose
Enhances the Universal Eligibility Wizard with accessible step progress meters, clear question hierarchy, mobile-friendly answer cards, contextual official notes, and screen-reader focus handling.

## Features
- **Accessible Progress Meter**: Communicates textual (`Step X of Y`) and visual (`role="progressbar"`) completion indicators.
- **Answer Option Cards**: Radio card presentation with high-contrast outlines and check indicators.
- **Associative Error Handling**: ARIA alert blocks associating field failures directly with the active fieldset.
