# Municipal Streetlight Outage and Dark-Spot Reporting Map

## Purpose
Enables citizens and resident welfare associations to map streetlight failures, damaged poles, exposed wiring, and unlit urban dark spots, routing reports directly to verified electricity distribution companies (DISCOMs) and municipal bodies.

## Key Features
- **EXIF Metadata Stripping**: Strips GPS, camera serials, and timestamp metadata from uploaded photos to safeguard citizen privacy.
- **Duplicate Report Clustering**: Detects overlapping reports within a 50m radius.
- **Non-Map Accessible Path**: Complete address and landmark input options for screen readers and low-bandwidth connections.
- **Official Complaint Generation**: Exportable summary formatted for municipal grievance portals.
