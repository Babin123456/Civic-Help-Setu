# Civic API Consumer Sandbox and Contract Test Portal

## Purpose
Provides external civic tech partners, academic researchers, and developer communities with an isolated testing sandbox containing deterministic synthetic fixtures, scoped test credentials, and machine-readable contract verifications without risking live citizen data.

## Key Capabilities
- **Production Isolation**: Strict separation between sandbox endpoints and live government integration rails.
- **Deterministic Synthetic Fixtures**: Guaranteed reproducible sample outputs for scheme discovery and eligibility simulation tests.
- **Credential Lifecycle & Rate Caps**: Expirable API tokens with 60 RPM rate-limiting protections.
