# Electricity Connection and Consumer-Name Transfer Guide

This document specifies the State DISCOM directory, application journeys, evidence checklists (sale vs. inheritance), and security deposit calculations for Civic Help Setu's Electricity Utility Guide.

## Problem Statement
When citizens move into a new house, buy resale property, or inherit an ancestral home, they face confusion regarding electricity utility administration:
1. **New Connection vs. Name Transfer**: Applying for a new meter when an active connection exists creates duplicate billing liabilities, whereas failing to transfer consumer names impedes solar rooftop subsidies and billing dispute resolutions.
2. **Inheritance vs. Resale Documentation**: Resale transfers mandate a previous owner consent NOC (Form U / Indemnity Bond), while inheritance transfers require municipal death certificates and legal heir certificates from the revenue tehsildar.
3. **Complex Fee Structures**: Upfront fees comprise refundable security deposits (calculated per kW of sanctioned load), service line development charges, and meter testing fees set by State Electricity Regulatory Commissions (SERCs).

## Journey Types & Evidence Matrix

```
  1. NEW_CONNECTION
     ├── Property Sale Deed / Tax Paid Receipt
     ├── Applicant Identity (Aadhaar / Voter ID)
     └── Licensed Electrical Contractor Wiring Test Certificate
           │
  2. NAME_TRANSFER (Ownership Change)
     ├── Zero Arrears Electricity Bill
     ├── Resale: Sale Deed + Prior Owner NOC / Indemnity Bond
     └── Inheritance: Death Certificate + Legal Heir Certificate
           │
  3. LOAD_CHANGE (Sanctioned Load Enhancement)
     ├── Additional security deposit calculation (per kW)
     └── Load feasibility verification by Sub-Divisional Engineer
           │
  4. PERMANENT_DISCONNECTION
     ├── Meter surrender form
     └── Final meter reading settlement & security deposit refund
```

## State DISCOM Benchmarks

| **BSES** | Delhi NCT | ₹1,500 / kW | ₹50 | DERC Ombudsman |
| **Generic State DISCOM** | Other States | ₹2,000 / kW | ₹100 | State SERC Desk |

## Security & Payment Integrity
- **Direct Official Portals**: Payments must be made directly on official DISCOM websites (`bescom.karnataka.gov.in`, `mahadiscom.in`, `bsesdelhi.com`); Civic Help Setu never collects bill payments or security deposits.
- **Privacy Preservation**: Consumer Numbers and CA numbers are not collected or stored.
