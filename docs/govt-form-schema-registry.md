# Government Form Schema Registry with Versioned Validation Rules

## Purpose
Provides a centralized schema registry for managing versioned government application schemas, field constraints, conditional rules, and official gazette / source references across state and central civic workflows.

## Key Capabilities
- **Provenance & Source References**: Tethers every field constraint to official legislative notifications and gazettes.
- **Privacy-by-Design Enforcement**: Automates contract checks rejecting schemas attempting to mandate Aadhaar, biometrics, or raw credentials.
- **Deterministic Rollback**: Facilitates instant rollback to prior approved schema versions when portal discrepancies occur.
