# Contribution Pathway Cards for First-Time Contributors

## Overview
Introduces dedicated, responsive contribution pathway cards on the Open Source / Contributor Hub page. Designed specifically to guide first-time contributors directly to actionable Good First Issues and relevant code locations across six distinct engineering and civic domains:
1. Frontend & UI Engineering
2. Accessibility & Screen Readers
3. Civic Service Data & Schemas
4. AI Policy & Safe Guidance
5. Testing & Chaos Automation
6. Documentation & Guides

## Key Features
- **Direct GitHub Search Links**: Directs users to targeted `label:good-first-issue` searches.
- **Repository Context**: Points users to specific subdirectories to start exploring.
- **Accessibility**: Includes ARIA lists, listitems, semantic headings, and descriptive link labels.
