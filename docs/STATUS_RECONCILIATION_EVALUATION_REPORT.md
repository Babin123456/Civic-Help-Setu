## 3. Boundary & Non-Goal Compliance Checklist

- [x] **No Authenticated Portal Scraping**: Voluntary copy-paste and manual entry only. Zero network requests made to government portals or scraping endpoints.
- [x] **No Credential Harvesting**: Passwords, OTPs, API keys, and session cookies are forbidden and stripped by `minimizeForExternal()`.
- [x] **AI Output as Untrusted Proposal**: Any text categorization is validated by deterministic regex-based vocabulary normalizers (`statusVocabularyNormalizer.js`).
- [x] **No Official Status Claims**: Explicit statutory disclaimer displayed on UI and modals indicating Civic Help Setu is an assistive utility, not a government body.
- [x] **Client-Side Data Minimization**: Zero server-side persistence; user controls data with single-click purge.
