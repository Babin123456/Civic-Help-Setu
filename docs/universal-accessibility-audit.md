# Universal accessibility audit workspace

`/accessibility-audit-workspace` provides a preliminary, user-reported checklist for selected benchmarks in the 2021 Harmonised Guidelines, an illustrative score and priority barriers, Section 89 penalty guidance, and a Commissioner petition template. It is not a professional assessment, legal advice, or proof of compliance. Unknown and not-applicable checks are excluded from the denominator; a score based on few answers can be misleading. Check current standards, facility-specific applicability, jurisdiction and evidence before filing.

Section 89 distinguishes first and subsequent contraventions; it does not automatically impose daily penalties. Section 90 addresses offences by companies. Applicable penalties and orders depend on the statute and competent authorities. The tool does not submit a complaint.

The vault stores only fixed checklist responses, a timestamp, random ID and SHA-256 digest. It does not store petition text, facility identifiers, contact information, or coordinates. Browser storage is unencrypted. The digest can detect accidental changes but is not a signature and can be recomputed. Clear records individually or through Clear my data (drafts); downloaded dossiers must be removed separately. Web Crypto in a secure context and functioning localStorage are required.
