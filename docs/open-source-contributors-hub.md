# Open Source Contributors Hub Documentation

## Redesign Overview (#561)
Transforms `src/pages/OpenSource.jsx` from a static placeholder page into a rich, dedicated **Community and Contributors Hub** for Civic Help Setu.

## Core Features
1. **Accurate Branding & Repository Anchors**:
   - Explicitly branded as **Civic Help Setu Community & Contributors Hub**.
   - Direct, safe links (`rel="noopener noreferrer"`) pointing to:
     - Repository: `https://github.com/GoldRay19/Civic-Help-Setu`
     - Issues: `https://github.com/GoldRay19/Civic-Help-Setu/issues`
     - Pull Requests: `https://github.com/GoldRay19/Civic-Help-Setu/pulls`
     - Contribution Guide: `https://github.com/GoldRay19/Civic-Help-Setu/blob/main/CONTRIBUTING.md`
2. **6 Clear Contribution Pathways**:
   - **Code & Core Engineering**: React, Vite, offline-first architectures, service workers.
   - **UI & UX Design**: Responsive design, plain-language formatting, accessible contrast.
   - **Accessibility (a11y)**: WCAG 2.1 AA compliance, screen reader support, keyboard navigation, reduced-motion.
   - **Civic Data & Scheme Guides**: Researching official government portals and updating statutory schemes.
   - **Testing & Quality Assurance**: Vitest unit suites, security linting, regression prevention.
   - **Documentation & Localization**: Translating procedural vernaculars, plain-language glossaries.
3. **Principles & Governance**:
   - Transparent, privacy-preserving, grounded in official sources, zero data harvesting.
4. **Interactive Quick Actions**:
   - Explore Good First Issues, review pull requests, read contributing guidelines.
